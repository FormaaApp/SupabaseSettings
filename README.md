# SupabaseBackend

## Описание

Основной бекенд сервис для работы мобильного приложения [KBJUCouchApp](https://github.com/FormaaApp/KBJUCouchApp).

## Начало работы

1. Заполните `.env.*` файлы в директории `env/`. Учтите, что все секреты, кроме `.env` будут лежать по тем же путям (без `.enc` расширения). `.env` будет перемещён в корень репозитория для совместимости с `run.sh` на стороне сервера после деплоя.
2. Добавьте `docker-compose.*` файлы в директорию `docker-compose-overrides/` и зарегистрируйте их в `COMPOSE_FILE=` через `:` в `env/.env`.
3. Добавьте миграции в директорию `migrations/`
4. Добавьте edge-функции в директорию `edge-functions/`
